Soukromí a bezpečnost

Tenhle web o tobě nic neukládá a nikoho nesleduje.

Žádné cookies ani sledování. Web nepoužívá cookies, analytické nástroje, reklamy ani sledovací kódy třetích stran.

Žádné účty. Nemusíš se registrovat a web po tobě nežádá žádné osobní údaje.

Hosting. Web běží na síti Cloudflare. Ta kvůli ochraně proti útokům zpracovává běžné technické údaje (např. IP adresu) podle svých pravidel ochrany soukromí.

Odkazy jinam. Odkazy na zdrojové články a kanály streamerů vedou na cizí weby, které mají vlastní pravidla.

Streameři. Profily obsahují jen veřejné informace o tvorbě. Pokud chceš svůj profil upravit nebo odstranit, napiš přes GitHub.
